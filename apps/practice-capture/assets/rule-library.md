# Practice question methods

Treat the attached question image as primary evidence. These are general methods, not an answer key. Prefer the simplest rule explaining the visible examples and distinguishing the answer options.

- Balances: cancel shared symbols, derive weight ratios, substitute into the target. Keep unconstrained symbols intact.
- Cube nets: check opposite-face pairs, then cyclic order of visible faces and orientation of asymmetric markings. A reflection may have the same adjacent labels in an impossible order.
- Spatial rotation: preserve connectivity, marked faces, distances and handedness. For top views, check cyclic order and distinctive edges.
- Visual matrices: track shape, count, position, rotation, shading, colour and arrows independently. A colour pattern alone does not resolve an arrow difference.
- Sequences: check simple differences, multiplication plus a constant, alternating operations and interleaved subsequences before complex fits.
- Equations: respect signs and operation order. Start arithmetic grids with the row or column having the most known values.
- Shape composition: match complementary boundaries and curves. Grid fragments may overlap at white cells; align the lattice rather than assuming disjoint tiling.

Classify the question, find the strongest distinguishing feature, form a simple coherent rule, and make one targeted check. Answer immediately once sufficiently supported. One minute is the maximum, never a waiting time. At the deadline return the best-supported option even if uncertain. Output only the option number counted left to right.
